# KMD《峰峰一中：青春纪元》Ultra 美术升级版

**KMD卡米达原创虚构娱乐项目，非峰峰一中官方产品。**

## 本次升级
- 美术方向：A 方案，精细像素艺术；目标等级 Ultra；覆盖全场景。
- 校园草地加入确定性像素簇纹理、地表层次和装饰绿化；树木改为多层像素簇树冠。
- 建筑统一为俯视屋顶、外墙基座、屋面分缝、设备、窗格、门廊和阴影体系，并按教学楼、宿舍、图书馆、实验楼、食堂、艺体中心、报告厅等类型区分配色。
- 学生角色改为正俯视像素人物造型；室内地面增加细节与材质层次。
- 保留原有玩法、操作、任务、地图和本地存档逻辑；主地图与小地图仍共享建筑坐标数据。

## 已确认的校园布局约束
- 手绘图上方为北、下方为南、左侧为西、右侧为东；游戏保持正俯视，不使用等距/斜视角。
- 操场在校园西侧，看台在操场左侧（西侧）。
- 弘毅楼A/B男生宿舍的连接部位在西侧，宿舍入口位于该连接部位。
- 弘德楼A/B女生宿舍入口位于两栋楼的连接部位；不将宿舍入口与校园主大门混为一谈。
- 杏坛报告厅朝西，室内舞台位于西侧，观众席朝西。
- 文渊馆为图书馆；格物楼为实验楼；行知楼为高一；省身楼为高二；海粟楼为高三；树人楼为政教处；求实楼为澡堂；思源餐厅为学生餐厅；艺体中心为体育与艺术活动场所。
- 校园主大门位置仍按用户提供的原始手绘图保留，独立于宿舍入口。

## 操作
- 电脑：WASD / 方向键移动，Shift奔跑，E互动，M打开地图，ESC退出室内。
- 手机：使用屏幕摇杆和互动按钮。
- 角色资料与存档保存在当前浏览器本地。

## GitHub Pages 部署
将 `index.html`、`style.css`、`game.js`、`README.md` 放在仓库根目录，提交并推送；在仓库 Settings → Pages 中选择部署分支和根目录。

## 十二章青春校园剧情升级
- 新增纯青春校园十二章主线：入学、班级生活、课间、餐厅、操场、图书馆、社团、同学沟通、实验体验、青春留言、校园汇演与成长回望。
- 每章提供两种选择；选择会累计成长记录分数，章节进度与支线完成记录保存在浏览器 localStorage。
- 新增 12 条校园生活支线，可在游戏内「剧情」→「校园支线」查看并记录完成。
- 游戏内点击底部「剧情」按钮打开剧情面板；主线章节可逐章推进，支线可单独记录。
- 本次剧情系统不修改任何校园建筑坐标、道路、入口、正俯视视角、男生宿舍西侧连接入口、女生宿舍连接部位入口、操场西侧看台及报告厅朝西布局。
- 剧情为虚构校园生活内容，不代表真实学校或真实师生经历。
